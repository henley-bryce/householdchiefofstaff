# Hub template

One shared page, sections in this order. The order is the review order: top is what needs action, bottom is reference.

| # | Section | What goes in it |
|---|---------|-----------------|
| 1 | **Quick Add** | A blank box either adult can type into at any time. Swept and cleared each week. |
| 2 | **Action Items & Owners** | Table: Task / Owner / Timing / Notes. Every task has a named owner or an explicit "Unassigned" flag. |
| 3 | **Weekly Review Order** | The review steps from SKILL.md Phase 3, so anyone opening the page cold knows the routine. |
| 4 | **Decisions Needed** | Checklist, one line per real decision. No nested sub-checkboxes (see triage-rules). |
| 5 | **Recurring Weekly Check-ins** | Questions that need a fresh answer every week (for example, who handles a recurring pickup). Resets each week. |
| 6 | **Travel Upcoming** | Table: Trip / Dates / Status. |
| 7 | **Birthday Radar** | Anything inside about 45 days: who, date, days out, gift status. |
| 8 | **School Closure Watch** | Closures inside the next 3 to 6 months, with a "coverage needed?" column. |
| 9 | **Things to Buy / Research** | Bigger-ticket items. Table: Item / For / Notes. |
| 10 | **Home Project Backlog** | Table: Project / Priority / Notes. Projects, not weekly to-dos. |
| 11 | **This Week** | Day-by-day table built from real calendar events, one row per day. |
| 12 | **Family Roster** | Name, age/birthday, school and activities. |
| 13 | **Standing Info** | Durable facts: standing arrangements, providers, nicknames, things to ignore. |
| 14 | **System Notes** | For the primary user only: filters, rules learned, last refresh log. |

## Formatting rules

- Use real tables for anything with columns, and checklists for decisions.
- Put the "last refreshed" date at the top.
- Keep the page scannable. Details live in the Action Items table or Standing Info, not in decision sub-bullets.
- Keep the hub free of passwords, account numbers, and financial detail.
